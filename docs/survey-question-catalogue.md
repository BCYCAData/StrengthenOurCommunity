# Survey question catalogue (proposed numbering)

Extracted from the current `src/components/form/surveyForm/Step2.svelte` through
`Step11.svelte` on 15 November 2026. The survey source is authoritative for the
wording, field names and order below. It does **not** currently define canonical
question numbers: the only existing numbers are the 12 navigation steps.

The machine-readable counterpart is [config/survey-questions.json](../config/survey-questions.json).
Its rules are implemented for review but remain pending coordinator approval.

The Q identifiers below are a proposed reference scheme, not numbers recovered
from the code. There are 35 main questions and six conditional follow-ups.
Step 1 is introductory text and step 12 is the closing message/save action.
No qualification requirements or exclusions have been adopted by this extraction.

Each question groups its answer fields; checkbox options and census categories
are not separate questions. Lettered IDs identify conditional follow-ups that can
be independently excluded. Q3a, Q3b and Q5a use field-label descriptions because
those inputs do not have their own question heading. Wording for the other rows
is extracted directly from question headings or `TextAreaInput.headingText`.

The profile section column maps the same fields to the profile editor. Survey
step numbers do not correspond directly to the About Me/My Place sections.

## Applicability and qualification notes

- Q3a/Q3b apply when rental status is Yes. Agent contact accepts either mobile
  or landline in the draft machine-readable rules.
- Q5a applies when truck access is Other (4).
- Q12b now consistently applies when livestock is present and the safe-area
  answer is Yes (`Y`), in both survey and profile editors.
- Q15a now consistently applies to Yes (`Y`), including when loading saved answers.
- Q9/Q11 group four counts each. Zero pets is a valid answer. Updated save handlers
  preserve blanks as NULL rather than zero; historical collapsed values remain
  ambiguous and require review.
- Q14 has None value 5. Q16, Q17 and Q19 now have explicit None value 0, mutually
  exclusive with substantive options. Empty selections remain unanswered.
- Q13, Q18, Q21, Q28, Q29, Q31, Q33 and Q35 are free-text prompts whose wording
  invites conditional/optional responses. Do not assume they must contain text
  merely because they have a catalogue ID.
- Q27–Q35 map to My Community, outside the proposed About Me/My Place scope.
  The final qualification policy must explicitly define its scope or exclude
  these IDs; that choice has not been made here.

## Using this catalogue for configuration

If adopted, freeze these IDs instead of regenerating them from display order.
Map stable IDs to fields and conditional rules; maintain the approved exclusion
list and rule version in Supabase. Excluding a parent must make its follow-ups
non-blocking, or the policy must explicitly state otherwise. No exclusion values
are supplied here because the required-answer decision is outstanding.

Question IDs are groups, not database-column numbers. The catalogue covers all
52 distinct named answer fields in the current survey steps. It does not include
fields that exist only in the profile editor, account registration, or legacy
survey data (for example postal address or `send_rfs_survival_plan`).
